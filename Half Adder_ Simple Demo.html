Half Adder

Adds two single bits. XOR gives the Sum, AND gives the Carry.

1. Choose binary inputs

Each input is one bit: 0 or 1. Click a button to flip it.

2. Circuit and program flow

Each stage has its own colour. A light glows when its value is 1.

3. The code

The highlighted line is the one running in the current stage.

5. Data structure used: the array

    
An array is an ordered list. Every item has an index starting at 0. These arrays update live.

    

      
steps

        
The four stage names. The stage buttons, the Run loop and the colours all use the index.

        

      
truth

        
The truth table rows [A, B, Sum, Carry]. The result is found by searching this array.

        

      
inputLog

        
Past inputs. Flip adds to the end with push, Undo removes the last with pop.

        

      
jsCode and cCode

        
Each line of code is one array item: [text, stage]. The stage decides its colour.
